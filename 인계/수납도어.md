# 인계 — 수납도어(키큰장·벽장·에어힌지) 도면 추가

작성 2026-09-07. **새 대화방에서 이 문서부터 읽고 시작하십시오.**
대상 파일은 `비규격작업지시서.html` 하나입니다. (로컬 도구 — 더블클릭으로 열립니다. 배포 앱 아님)

---

## 1. 지금까지 한 일 (캐드 양식)

`[📐 캐드 양식 생성]` 버튼(`cadGenerate`)이 A4 SVG를 직접 그립니다. 기존 `[작업지시서 생성]`(`generate`)은
살려 둔 상태입니다 — 유리 발주 탭과 EURO500 처리가 아직 그쪽에도 얽혀 있어 아직 지우지 않았습니다.

한 페이지 구조: **머리글(발주일·업체명 / D-2·현장명·납품일) → 계열 띠 → 블록들**.
블록 하나 = **왼쪽 도면 + 오른쪽 글자(코드 / 색상 / 완성치수=수량 / 재단치수)**.

## 2. 도면이 붙는 자리

| 함수·상수 | 하는 일 |
|---|---|
| `DOOR_LIB` | 코드 → 캐드 SVG 문자열(치수선·치수문자·보링마커 포함). DXF 실측 16종 인라인 |
| `libDoor(code,type)` | 코드+계열(OB/HD) 우선, 없으면 계열 폴백 |
| `DOOR_ALIAS` | 같은 도면을 쓰는 코드 연결 (`W2HBT → M`) |
| `libDoorFilled` | 도면 안의 `X·Y·Z·A` 자리를 실제 값으로 바꿈. **DOM 텍스트 노드 단위** — 정규식 문자열치환 금지 |
| `cadRealViewBox` | `getBBox()`로 실제 범위를 재서 viewBox를 넓힘(빨간 강조원이 잘리지 않게) |
| `cadDoorSize` | 넓이 정규화 — 가로세로 비가 달라도 눈에 비슷한 크기로 |
| `cadEmbedDoor` | 도면을 페이지에 앉히고 **치수 글자를 확대 배율만큼 역보정**해 항상 같은 크기로 |
| `libDoorDimTextOnLine` | 치수 숫자를 치수선 위에 90° 세워 정렬. 선에 물릴 것 같으면 칸 바깥으로 뺌 |

**새 도면을 넣는 일 = `DOOR_LIB`에 항목을 더하는 일**입니다. 그리는 로직은 건드릴 것이 없습니다.

## 3. 눈금 하나로 조절되는 상수들

```js
CAD_DOOR      = { AREA_MM2:1600, MAX_W:62, MAX_H:62, MIN_H:20, DIM_MM:4.0, PAD:0.04 };
CAD_DOOR_SCALE= { M:0.8 };        // 코드별 크기 배율
CAD_DOOR_DY   = { WT:-2.5 };      // 코드별 세로 미세 조정(+아래 / −위)
CAD_BLOCK_X   = 31;               // 블록 시작 x(mm) — 좌우 쏠림
CAD_BANNER_H  = 13;               // 한 장 안에서 계열이 바뀔 때 넣는 중간 띠
CAD_LAYOUT.MAX_DRAWINGS           // 한 장에 들어갈 서로 다른 코드 수
LR_SPLIT_CODES= new Set(['WHBT']);// 좌우(L/R) 나눠 수량 세는 코드
CAD_HANDLE_DRAW / CAD_HINGE_REDRAW// 손잡이·힌지를 코드로 다시 그리는 코드 목록
WHBT_BANDS                        // 납품서 세로 구간별 힌지 위치
```

세로 맞춤 규칙(2026-09-07 확정): **짧은 쪽을 긴 쪽 가운데에 맞춥니다.** 도면이 길면 글자가 내려오고,
글자가 길면 도면이 내려옵니다(단 도면은 두 줄까지만 — 약어줄에서 멀어지지 않게).

## 4. 수납도어에서 새로 정해야 할 것

1. **계열 띠(배너).** 지금은 `EURO700 HD / EURO700 OB / EURO500` 셋뿐입니다(`cadGenerate`의 `byType`·`BANNER`).
   키큰장·벽장·에어힌지는 **새 계열**이라 분기를 늘려야 합니다.
2. **계산 규칙.** 현재 `calc`는 유로 계열 전용입니다(프레임 = 납품 −5×−4, 유리 = 프레임 −0×−손잡이값 …).
   **수납도어 감산값은 아직 확인되지 않았습니다. 추측해서 넣지 말고 사용자에게 물어보십시오.**
3. **리드타임**(참고, `리드타임.md` 정본): 유리장식벽장·키큰장 **정규격 5일 / 비규격 6일**, 에어힌지 **7일**.
   판정 순서 함정 주의 — **에어힌지·빗각/빗면·KB를 "유리장식|장식장|키큰장"보다 먼저** 봐야 합니다.
4. **탭을 따로 뺄지.** 도면 계통이 완전히 다르므로 유리장식은 별도 탭으로 가자는 이야기가 이미 있었습니다.
   먼저 결정하고 시작하는 편이 낫습니다.

## 5. 결과를 눈으로 확인하는 방법

로컬 파일이라 화면 캡처가 막힙니다. 아래 방법으로 확인했습니다.

1. PowerShell `HttpListener`로 프로젝트 폴더를 띄웁니다.
   **한글 경로 함정** — PowerShell 5.1이 UTF-8 스크립트를 ANSI로 읽어 경로가 깨집니다.
   스크립트 안에 한글을 쓰지 말고 **환경변수(`$env:CADROOT`)로 폴더를 넘기십시오.**
2. 시험용 자료 주입: `ROWS`는 `let` 전역이라 `window.ROWS=` 로는 안 바뀝니다.
   → `ROWS.length=0; 자료.forEach(r=>ROWS.push(r)); cadGenerate();`
3. `.cad-page`의 SVG를 canvas로 그려 PNG로 만들고 서버의 `POST /save?name=` 로 넘겨 파일로 봅니다.
4. 넘침 검사: 페이지 SVG의 **직속 자식**만 훑어 최대 x·y를 봅니다.
   내용 박스는 **x 201.25 / y 288.25(mm)** 가 끝선입니다.

## 6. 아직 사용자 답을 기다리는 것

- WHBT **힌지 3개짜리 도면** — 주시면 `CAD_HINGE_REDRAW`에서 `'WHBT'`를 빼고 라이브러리 도면으로 바꿉니다.
- **OB 손잡이 모양** — 주시면 `libDoorDrawHandle`을 OB까지 넓힙니다.
- `generate()`(옛 렌더러) 퇴역 여부 — 유리 발주·EURO500을 캐드 쪽으로 옮긴 뒤에 결정합니다.
- `CLAUDE.md` 11-9의 B·C·D 현장 확인 항목(WT 힌지 380/384, BD2R 상부마이다, BD3U A값).
