## 이 폴더의 규칙

- **숫자·규칙을 여기 새로 적지 마십시오.** 확정된 수치는 `CLAUDE.md`, 리드타임은 `리드타임.md`가 정본입니다.
  두 곳에 적으면 반드시 어긋납니다.
- **사장님 답을 기다리는 것은 [`확인대기.md`](../확인대기.md)** 한 곳에만 적습니다.
  여기에는 "→ 확인대기.md B3" 처럼 포인터만 둡니다.
- 인계 문서는 **그 앱을 어떻게 만들었는지**(구조·파일 위치·검증 방법)를 담습니다.
